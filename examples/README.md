# Examples

Everything here is invented: the papers, the authors, the reviewers and their
comments. Run either folder with `review-desk serve` from inside it.

- `synthetic/` — a 2-page LaTeX (revtex) letter on a splitting integrator,
  7 comments from 2 reviewers in Markdown. One anchor is deliberately stale
  (R2.3) to show the build report; R1.2 is anchored inside a display
  equation; R1.3 has no `@anchor` and is placed by its quoted phrase.
- `markdown/` — a short Markdown paper with reviews in JSON, Chinese UI.
